PiShell

A phone and desktop shell for a home server. It finds your Pi on the LAN, then wraps whatever web apps that Pi already serves in one launcher, so each one opens like a native app instead of a browser tab.

Point it at your own server: it ships with no address of anyone else's baked in. See hosts.example.json in the repo for the one file it needs.
